# 🎮 JUEGO | MAZE EN BITSY | ING. EN VIDEOJUEGOS

¡Bienvenidos al proyecto de **Maze desarrollado en Bitsy**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **[Nombre de la materia]**.

A través de este ejercicio podrás explorar cómo crear un laberinto interactivo utilizando Bitsy, diseñando recorridos, espacios y caminos que permitan al jugador desplazarse por el escenario hasta encontrar la salida.

## 🎯 Objetivo del proyecto

Desarrollar un laberinto interactivo utilizando Bitsy, poniendo en práctica los fundamentos del diseño de niveles, la navegación espacial y la construcción de recorridos dentro de un videojuego.

## 🛠️ Tecnologías utilizadas

- **Herramienta de desarrollo:** Bitsy
- **Tipo de proyecto:** Laberinto (*Maze*)
- **Género:** Exploración y resolución de laberintos
- **Estilo visual:** Pixel art
- **Tipo de experiencia:** Videojuego 2D interactivo

## 📂 Archivos del proyecto

### Proyecto y recursos

En este repositorio encontrarás los archivos correspondientes al laberinto desarrollado en Bitsy.

Puedes explorar cómo se organiza el escenario, cómo se construyen los caminos y cómo se distribuyen los espacios para crear un recorrido que el jugador debe completar.

## 🎓 Uso educativo

Este proyecto está destinado a fines educativos y forma parte del material de apoyo de la carrera de **Ingeniería en Videojuegos**.

Puedes utilizarlo como referencia para estudiar los fundamentos del diseño de niveles y comprender cómo una herramienta sencilla permite crear experiencias interactivas mediante escenarios, exploración y navegación.
