# 🎮 JUEGO | MAZE EN BITSY | ING. EN VIDEOJUEGOS

¡Bienvenidos al proyecto de **Maze desarrollado en Bitsy**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **[Nombre de la materia]**.

A través de este proyecto podrás explorar una experiencia de exploración basada en un laberinto (*Maze*), creado con Bitsy. El jugador deberá recorrer el escenario, encontrar el camino correcto y descubrir la salida, utilizando las mecánicas básicas de movimiento y navegación.

## 🎯 Objetivo del proyecto

Desarrollar un laberinto interactivo utilizando Bitsy, poniendo en práctica los fundamentos del diseño de niveles, la navegación espacial y la construcción de recorridos dentro de un videojuego 2D.

## 🛠️ Tecnologías utilizadas

- **Herramienta de desarrollo:** Bitsy
- **Tipo de proyecto:** Laberinto (*Maze*)
- **Género:** Exploración y resolución de laberintos
- **Estilo visual:** Pixel art
- **Tipo de proyecto:** Videojuego 2D interactivo
